# slbb-chatcut-huoke

通过 WorkBuddy、豆包工作、Codex 等宿主调用 ChatCut，精剪口播与讲解视频。当前版本：**v2.7.3**。

## 安装

把下面这段交给你使用的 AI 宿主：

```text
请安装 https://github.com/slbb1995/slbb-chatcut-huoke 中的 slbb-chatcut-huoke Skill。
先阅读 README 和 LICENSE；完整安装仓库内 slbb-chatcut-huoke 文件夹，保留参考文档、脚本、许可和内置音乐。
如果已有同名 Skill，先备份，并保留我的行业词表和已确认配置；不要创建第二套活跃副本。
安装后检查能否读取 Skill，并实际验证 ChatCut 客户端连接，分别告诉我安装和连接结果。
```

也可以[下载完整 v2.7.3 安装包](https://github.com/slbb1995/slbb-chatcut-huoke/releases/download/v2.7.3/slbb-chatcut-huoke-v2.7.3.zip)，在宿主支持的 Skill 导入入口导入，或使用解压后的同名文件夹。校验文件见 [Release](https://github.com/slbb1995/slbb-chatcut-huoke/releases/tag/v2.7.3)。

打开并登录 ChatCut，确认宿主能调用客户端工具。首次使用建议提供行业和客户术语。主口播必需，文案、B-Roll、音乐可选；不限时长，默认约 1.15 倍速、竖屏 1080P/30fps。剪完先给预览，确认后导出。
