# 常用词与辨词边界

本表在字幕阶段读取，辅助本人的 AI 工具、企业服务及剪辑口播；不要求视频出现这些词，不限定题材。只收录已在用户指令、资料或素材中出现的词，不扩成通用百科。

## 工具、产品与概念

| 推荐写法 | 核对要点 |
|---|---|
| WorkBuddy | 保留 W/B 大写；本次素材出现过 ASR 的 Workbody，须结合语境确认后纠正。与 Codex 是不同产品。 |
| Codex | 保留首字母大写；不要因近音替换成 WorkBuddy，也不能把普通“代码”等词套成 Codex。 |
| ChatCut | 剪辑工具名，C/C 大写；不能与 ChatGPT 互换。 |
| 豆包工作 | 用户当前使用的宿主称呼；不要把普通“豆包”一律补成“豆包工作”。 |
| ChatGPT | 保留 GPT 大写；与 ChatCut 分别核对。 |
| DeepSeek | D/S 大写，保留完整单词。 |
| Obsidian | 笔记工具名；遇音译/近音先结合知识库、笔记等上下文判断。 |
| 飞书 | 工具名，不能把近音普通词全局替换。 |
| Skill / Skills | 技能；根据实际单复数保留，不强行把说出的中文“技能”翻成英文。 |
| Agent / AI Agent | 智能体；根据实际说法保留，不与 Agentic AI 混用。 |
| Agentic AI | 保留两个词；不能因词长或陌生缩成 Agent。 |
| AI / Gen AI / 生成式 AI | 保留实际说法，AI 大写；这些概念不能因同属 AI 而互相替换。 |
| 工作流、智能体、知识库 | 连同前后句判断，保留真实中文表达。 |

工具与概念来源：本轮用户指令、既有《原话包-工作流Skill与AI协作》及《一张图看懂 AI、生成式 AI、Agent 和 Agentic AI》。来源用于确定常见词和拼写，不证明任一视频的实际用词。

## 增补

用户明确提供或纠正的常用词，在已有维护授权下补到这一个文件，简记正确写法、容易混淆处及依据，不为逐个加词再询问。只在单条视频出现的客户名、临时活动名和未证实候选先留在任务记录，不自动写成长期口径。无 Skill 写权限的宿主在任务记录中标记待同步，不假称已持久保存。

相近发音只是查错线索，不是替换规则；尤其禁止 Codex → WorkBuddy、ChatCut → ChatGPT、AI Agent → Agentic AI 的全局替换。
