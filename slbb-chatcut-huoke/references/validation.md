# 真实测试与覆盖

用用户授权的素材和宿主，保留原文件、建独立工程。授权自行选一条就直接选，不因缺 B-Roll 或音乐阻塞，不用无关素材凑分支。

验证：首次提醒不阻塞剪辑，客户词表不混用；真实连接/正确工程；先读完整口播文案，剪后内容与删改方案一致，口头语按句意清理且自然气口保留；默认 1.15 倍速且保源范围；字幕文本/时间/最多两行/安全区及真实画面；标题实际起止与内容转折对应，形式不限且可读；已有包装不叠加；人声/必要降噪/音乐长度；有 B-Roll 才验小窗同步静音。获客信息不补造、辅助画面不冒充当前案例；发现字幕疑点主动核对。没有的分支明确未实测。

预览可通过客户端导出，命名 preview_*，按当次约定验证编码、尺寸、fps、音频、时长与解码；不伪造预览确认换取正式完成状态。不限制一分钟，不强制获客结构，只按用户明确要求验收。

交付验证：当次目标路径明确，正式成片可读且与确认版本一致；按实际目录命名，不覆盖原片。目标交付处仅新增用户要求的最终成片，工程和检查资料留在工作目录；未指定位置时不固定猜测某个电脑路径，也不阻塞独立的剪辑与预览工作。

报告素材、宿主、工程、输入/输出时长、主要改动、实测耗时、错误修复、预览和未覆盖项。未实际运行的宿主不算通过；文件/YAML 验证不代表剪辑跑通。

维护时校验相对引用、YAML、音乐哈希；未改脚本不重复造测试工程。打包排除用户元数据/缓存/任务文件，不自动 Git 同步或更新飞书附件。
