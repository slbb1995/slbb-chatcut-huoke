# 字幕质量与操作

## 内容与来源

以实际口播为准，文案辅助专名、数字和同音词。重点检查否定词、金额、条件，不补未说内容。区分烧录字幕与可编辑字幕，已有合格字幕不重复叠加。

只以主口播音频提供字幕。读取真实 caption source/track，不假设叫 V1 或 enable 必定生成所有轨；出现辅助字幕时隐藏其字幕轨，不是视频轨。B-Roll 期间主口播字幕保持显示。

## 纠错、模板与分卡

1. 主轨剪切先完成。改字幕拼写从 read_captions → set_card_text 开始，不把源纠错/重转写设为前置。只有用户明确要求修复源或错误影响剪切定位时才按当前源维护指南操作；源变更后刷新 Script，重新读取受影响字幕。
2. 采用明确偏好或一种可读模板，不额外要求选样式。先套基线，再读最新 Card ID，避免模板重分卡使 ID 失效。
3. 按完整短句、停顿、并列项分卡；split_card 从当前 read_captions words=true 取得真实 token，格式以当前 schema 为准，不猜字符偏移。
4. 独立修正可原生 batch 提交；不在批次内引用尚未返回的新 ID。接口暴露 revision 时带当前值，未返回则不猜；stale 时先读回。

不以空串/空格删卡，不隐藏溢出或裁后半句；不写有旧版破坏记录的 maxLines。每卡最多两行依靠分卡、宽度及画面验证，不缩成小字。旧故障不是新版本必然行为，但不在真实工程中试险。

单行优先，两行可用，产品名、金额、中文复合词不拆碎。第二行避免只剩一两个字，以语义调整边界而不改写原话。时间对应真实语音，不重叠闪烁或拖过下一句。

## 安全区与验收

默认左右各留宽 10%，顶部留高 5%，底部留高 20%。1080×1920 的完整外框在 x=108…972、y=96…1536，包含描边/背景/阴影/动画极值，避开小窗和重要内容。用户平台或边距要求优先；这不是平台无遮挡保证。

优先轨道/模板统一布局，再修少数例外。接口成功不能证明像素生效。检查全部卡内容/时间/行数/布局，长句、数字、英文、明暗变化和相邻卡边界看真实画面。听不清且影响意思时说明，不编造。没看画面只能报告文字结构已检查。

## 全片校对与常用词

使用 [当前行业/客户词表](terminology.md)，从本条素材补充临时专名；不混用其他客户资料。词表辅助辨词，不替代原声与完整句意。字幕、标题及其他屏幕文字的同一名称保持一致。

每次初剪或用户要求重查整片，完成以下一次校对，不新增确认步骤：

1. 分页读取全部卡至 hasMore=false；按返回的 nextOffset 继续，不能以请求 limit 判断已读完。连接相邻卡还原整句，从头到尾检查错字、同音词、漏字/重复、主谓关系、否定/条件、数量/单位、指代与并列关系，不只搜索英文名。
2. 对可试听的主口播逐句对照，重点回听疑点及前后文；再用用户提供文案、画面中的名称和词表核实专名。文案或词表只能证明候选拼写，不能证明这次确实说了该词。保留真实口语，不为语法顺畅补出未证实的字。
3. 有依据的错误在字幕层集中修正，记录时间、前后文本和依据；标点/大小写/空格整理与识别纠错分开记录。产品名不拆断，跨卡组合不丢字、不重字，长句不压缩成另一种意思。
4. 读回全部最终字幕，核对修改没有牵连其他卡；检查每卡实际显示，重点看长句、数字、英文和改动卡。既有预览对应当前字幕时可复用，不重复渲染未改部分。

首次剪辑发现疑词、句意异常或转写分歧时主动核对原声，不等用户提醒；用户明确要求时也执行。无法直接听音则用已连接的识别能力处理实际音轨：局部疑点带前后文核对，要求全片复核时比对原声与成片全文，不覆盖原工程的源转写。需要时去配乐、适度降噪、恢复原速，检查片段尾句完整。结合音频结果、语境与可见名称判断，不靠重复提交投票；无疑点不强制额外转写，重读旧转写不算音频核对。

完成可用的音频核对后仍不确定，或实际没有可用识别途径时，在结果中标出具体时间和疑点，保留原文，不猜改；继续完成能核实的部分。只做文字/画面检查不能称为“已逐字听校”或“全片无误”。同一 ASR 文本的不同导出不是独立验证；缺失/默认置信度也不能当作真实概率。若转写接口明确支持术语提示，仅把本条相关词作为提示，不猜参数、不为加词重复转写。

## 顶部标题

标题的任务是写清本条主题。用户文字优先，否则忠实概括；形式不固定，不把某条样片的字体、颜色、描边、衬底、单双行或对齐方式固化为模板。按实际画面选清晰协调的字重、层级和留白，避免遮住人脸与操作信息；“高级”不能只靠装饰堆叠或低对比小字实现。

出现时段按内容判断：开场已经交代清楚主题后，可在进入下一项演示或段落时退出；需要持续提示时可保留，用户指定时优先。不要默认全程常驻，也不把“约 20 秒”或一次样片的退出点设为统一时长。记录这条视频实际采用的起止时间与内容依据，淡入淡出可按需要使用。

标题使用独立层，不绑到某张口播字幕卡；在计划显示的时段内不因真人/B-Roll 切换意外消失，计划结束后不残留。已有合适标题不叠加。小窗仍固定右上角，与标题显示范围及主字幕互相避让，不自动左右换位。检查开场、明暗背景、退出前后和结尾。可用原生标题或项目内可编辑 SVG 实现，不需要付费生成。
