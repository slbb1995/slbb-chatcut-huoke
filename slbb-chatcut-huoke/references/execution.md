# 连接、Script 与视觉同步

## 连接与当前能力

宿主负责推理并调用客户端，不转交内置 Agent。读取本阶段真实 schema 后复用。官方能力指南和用户 Workflow Skill 不是同一目录，manage_skill 未必提供内置指南，按宿主实际文件/工具入口读取。

当前外部工具显式要求 projectId，发现/打开窗口不绑定后续调用。旧版仅支持活动工程时检查目标，别把工程切换当字幕损坏。建工程显式设方向；返回关闭工程不等于失败，需要窗口的操作按实际能力打开。

使用本工程真实素材 ID，不跨工程硬套，不重复导入已存在素材。轨道不存在才创建；当前可能支持别名自动建轨，旧版可能需 edit_track create。

已配置且获准的本地连接可用 scripts/chatcut_mcp.py 的 list-tools、call --tool <真实名称> --args-file <参数文件> 或 batch --calls-file <调用列表>。包装器不安装、授权或改配置。批次按顺序执行，只合并已有 ID 且不依赖新结果的调用。预览导出用 --preview-export，正式导出用 --state-dir 与 --revision 通过门禁。不绕过宿主拒绝。

## Script 与提交

需要修复源时，源纠错先于依赖它的 Script 和最终字幕；普通字幕拼写修正不必改源。读真实字/词索引，不从显示字符数猜；源变更后刷新 Script 再编辑，避免 stale/words 校验冲突。当前 Desktop 实测命令为 `FIX [s2]: 8 -> "WorkBuddy"`（保留方括号，索引取 inspect_asset 返回值）；旧版无方括号命令会被拒绝。

机械清理仅处理明确口癖与长停顿，语义删减走 read_script → 编辑返回路径的 timeline.md → apply_script。未提交 Script 不再调用会重建它的读取。保留锚点和有用内容，不用空白 gap 制造主轨黑屏。

文案精剪先理解整句，再标记删除和局部调序；不是把润色后的文案直接覆盖源转写。带停顿改写的行按当前 Script 合同保留完整原句，用删除线标出不保留的词，避免将裁短后的句子误判为改写源词。应用后把当前实际保留内容与删改方案逐句对照，字幕显示中因边界取整残留的字另在字幕层校正，不能以只改字幕冒充已剪掉讲话。

检查 JSON-RPC error、isError、业务失败和文字诊断，不以退出码 0 证明写入成功。不确定回执先读回，pending/running 追踪原作业，不重提。不并发修改同一工程。

## 倍速与视觉同步

单位从 schema 确认，当前常见为时间线帧和源微秒。改速前保存每段选中源起止；源消耗 = 时间线帧数 / fps × playbackRate。1.1 倍速应缩短时间线占位并保留原选段，按帧精度取整、回读源尾。不能借读被删内容或下一段。

源时长 S 秒对应目标帧数约 S / rate × fps，按工具取整与边界约束处理。linked picture/audio 一起调整，主轨相邻位置连续。不能把下一段 sourceIn 推到上一段 sourceOut 来消除重叠；无法安全提速时恢复原选段与原速并说明。

主轨定稿后放 B-Roll/小窗，映射：source_seconds = source_start_seconds + (timeline_frame - item_start_frame) / fps × rate。跨边界小窗拆段，逐段匹配源、倍率、位置与时长；主轨改变后重算副本。

新版可能分离 picture/audio：辅助画面优先 picture-only（schema 支持时），否则定位真实音频对象静音。不能只改无声音的视频对象就宣称静音；-60dB 不等于真静音。

横屏素材按内容 cover/contain，检查旋转、主体与重要信息。仅实际解码不兼容时另存兼容副本，不全量预转码，不覆盖原素材。

小窗在整条视频固定右上角，所有片段使用同一套位置和尺寸；标题下方预留间距，不因不同 B-Roll 自动左右换位。主体遮挡优先通过 B-Roll 选段/构图处理，不能以避让为由擅自移到左侧。
