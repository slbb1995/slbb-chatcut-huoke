# slbb-chatcut-huoke · v2.7.3

**使用许可：仅限个人非商业使用；商业获客、企业使用、收费代剪及其他商业用途须另行书面授权。详见 [LICENSE](LICENSE)。**

将一条口播或讲解交给已连接 ChatCut 的 WorkBuddy、豆包工作、Codex 等宿主。主视频必需，文案、B-Roll、音乐和最终保存位置可选；明确同属一条内容的连续主片段可合用，不自动批量剪多个作品。

首次安装后使用时，上传或粘贴你们行业和当前客户的常用话术、品牌/产品名、专业词及标准写法，让宿主替换 [行业与客户词表](references/terminology.md)。已有介绍或口播稿即可，暂时没有也能先剪。切换客户时提供对应资料，避免混用原客户词表。

默认先提取完整文案，再清理口误、重复、多余口头语和过长停顿，保留事实、原意、自然气口及有用的获客信息；不补录音没有的卖点或引导话术。默认 1.15 倍速，过赶或失真恢复原速，不为凑一分钟删内容。

字幕简体、显眼完整、最多两行；专业词结合当前客户资料和原声核对，发现疑点主动复核。标题按内容决定形式与出现时段。有相关 B-Roll 时安排辅助画面和同步真人小窗，小窗固定右上角。已有字幕、标题或音乐先识别，避免重复叠加。

声音以人声为主，用户音乐优先，否则内置轻配乐；明确不要就不加。内置音乐从 -26dB、无额外 duck 起步，换录音或音乐后复核。明确要求降噪或未带麦且噪声大时实际处理，其他情况按录音判断。

默认输出 9:16、1080×1920、30fps、H.264 MP4，当次指定规格优先。无额外问卷、选模板或中途审核；要求先看文案时才先交稿。剪完给预览，确认当前版后正式导出；测试任务可直接导出明确标记的预览。

正式交付按当次指定路径；未指定时不妨碍剪辑，在正式导出前一次问清。目标位置只新增最终成片，工程、转写和检查资料留在工作目录；不覆盖原文件，不自动归档、同步或发布。

Python 脚本辅助连接、流程记录与技术检查，不替代 ChatCut 剪辑。安装完整包，已有同名包先备份。详见 [SKILL.md](SKILL.md)。
