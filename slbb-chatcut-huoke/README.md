# 单条口播剪辑 · v2.7.1

在 WorkBuddy、豆包工作、Codex 等能读取 Skill 并调用 ChatCut 客户端工具的宿主中使用。适合以讲话为主的各类内容，无一分钟限制。主视频、可选文案/B-Roll/音乐交给宿主，剪完预览，确认后正式导出。

当前宿主必须已具备连接和所需权限；本包不安装 ChatCut、不改配置、不调用图片/视频/音乐生成服务；普通文字标题直接制作。各宿主安装入口以本机为准；维护共享目录时不要额外复制第二个活跃版本。

使用说明见 [使用说明.md](使用说明.md)，入口规则见 [SKILL.md](SKILL.md)，示例见 [一键提示词.txt](一键提示词.txt)。旧版经验移到按需参考；历史变更保留在 CHANGELOG.md，历史规则不覆盖当前入口。

辅助脚本与内置音乐保持原有功能。v2.7.1 的验证范围以本次实际测试记录为准，不以旧版案例证明新版本或其他宿主已通过。不自动 Git 同步或更新远端分发附件。

先提取并理解完整口播文案，再按语义精剪多余口头语、重复和停顿，保留自然气口；用户要求先看文案时才先交稿。顶部标题写清主题即可，字体、排版和出现时长按内容判断，不固定全程或 20 秒，也不固定某次样片的视觉样式。

剪辑与保存位置分开：本技能负责剪辑、预览和成片导出，位置按当次用户或上游指令；未明确时在正式导出前问清，不妨碍先剪辑和预览。要求放回对应素材文件夹时沿用其结构与命名，只新增最终成片；工程、转写、预览和检查文件留在工作目录。复杂归档或同步另由对应工作流负责，不为一次保存新增 Skill。

保留已确认的其他规则：专名按词表核对；明确要求降噪时实际处理全体主口播；默认人声为主、BGM 轻轻铺底。内置音乐以已确认的 -26dB、无额外 duck 为参考起点，换录音或音乐后复核，不因配乐不明显而抬高。

画中画固定右上角，同一视频统一尺寸和位置，不自动左右切换；有顶部标题时放在标题下方。

字幕先读 [常用词表](references/terminology.md)，再逐句核对整条视频的错漏、句意、数字和断句；词表覆盖常见 AI 工具与概念，不只检查两个英文名，也不把不同产品互换。无法试听的疑点如实标注，不增加中途确认。
