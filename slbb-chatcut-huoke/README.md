# 获客口播剪辑 · v2.7.3

**使用许可：仅限个人非商业使用；商业获客、企业使用、收费代剪及其他商业用途须另行书面授权。详见 [LICENSE](LICENSE)。**

在 WorkBuddy、豆包工作、Codex 等已连接 ChatCut 客户端的宿主中，将一条已有口播或讲解剪成清楚、自然、重点突出的视频。面向多个行业，以获客用途为主，兼容其他讲话类内容；不限时长，不强套营销结构。

首次安装后使用时，请上传或粘贴行业和当前客户的常用话术、品牌/产品名、专业词及标准写法，已有介绍或口播稿即可。宿主据此填写并替换 [行业与客户词表](references/terminology.md)，以后按适用对象取用；暂时没有也可以先剪，只提醒一次，不要求填写问卷。

默认 1.15 倍速，过赶或失真时恢复原速；9:16、1080×1920、30fps、H.264。画中画固定右上角，标题形式与时长按内容判断，人声为主、轻音乐铺底。先读全文再精剪，有字幕疑点主动核对。正常流程只在剪完后确认预览，再按当次位置正式导出。

需要可用的客户端连接和素材权限。本包不自动安装软件、改配置、生成媒体、归档或同步文件。共享目录只维护一个活跃版本。历史条目仅作记录，当前规则以 SKILL.md 及其参考为准。

剪辑规则已在 Codex 调用 ChatCut 的真实口播中验证，含去口气词、字幕复核、B-Roll 与词尾时间越界修复；本次许可与打包更新未重复剪辑，未声明其他宿主已实测。各版本覆盖见 CHANGELOG.md。
